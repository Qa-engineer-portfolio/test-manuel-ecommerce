# Tests manuels — Application de commerce électronique
#### 1. Présentation du projet
Ce projet de QA porte sur les tests fonctionnels manuels d'une application de commerce électronique "SauceDemo" : https://www.saucedemo.com/.<br>
Il s'agit d'un projet personnel d'apprentissage réalisé sur une application de démonstration. Les résultats des tests et les éventuelles anomalies seront documentés à partir des observations réellement effectuées lors de l'exécution des tests.
#### 2. Objectifs
* Concevoir des cas de test.
* Exécuter les cas de test et consigner les résultats obtenus.
* Identifier, documenter et signaler les anomalies détectées.
#### 3. Livrables
* Plan de test
* Cas de test
* Rapports d'anomalies, si des anomalies sont détectées
#### 4. Outils utilisés
* Microsoft excel
* Github
* jira
* git
